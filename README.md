# Pop Clicker

A balloon-popping idle game in a single web page. Pop the balloon with an ever-sharper needle, hire monkeys that
circle it with pins or throw darts from a distance, train them, buy balloon colours that multiply every pop, dress the
balloon and the monkeys in hats, and keep the Monkey Union happy.

## Run it

Open `index.html` in a browser. It needs an internet connection only for the fonts and three.js (the 3D monkeys);
everything else, including the photos in `photos/`, is local. Progress is saved in the browser.

For the best results serve the folder over HTTP, for example:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

## Features

- Nine needles, eight monkey types (with three upgrade tiers each), nine balloon colours with their own pop sounds
- 3D sitting monkeys (three.js) in full-body mode, a heads-only mode, and a photorealistic mode using real photos
- Balloon hats and monkey hats, an ascension cutscene for the Halo
- Monkey Union panel with complaints, an evolving union, standing that changes worker speed, and timed choices
- The Daily Peel newspaper clippings and news blimps for big events
- Four original synthesised music tracks, realistic sound effects in photorealistic mode
- Backgrounds, statistics and settings
